# Getting Started

This guide explains how to get started with `async-gem_kit`.

## Installation

Add the gem to your project:

~~~bash
$ bundle add async-gem_kit
~~~

## Core Concepts

`async-gem_kit` is an async-native library built on the
[Socketry](https://github.com/socketry) ecosystem.

## Usage

~~~ruby
require "async/gem_kit"
~~~
